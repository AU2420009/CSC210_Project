# CSE210 Project (Group 4)

This project is a digital library management system with various features. Java source code can be found in the `/src` directory.

This is a multi-file project. Data structure implementations are located in the `/datastruc` directory while `Main.java` contains the main logic.

To compile the project, please invoke the following command:
`javac -cp ./datastruc Main.java`

To run the compiled project, invoke the following:
`java -cp ./datastruc/:. Main`
